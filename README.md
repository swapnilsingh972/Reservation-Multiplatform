The SentinelAI dashboard is designed to be intuitive:

- **Traffic Overview Chart** – Shows network activity over time. Green means normal, red means suspicious.
- **Attack Alert Table** – Lists any detected threats with severity levels (Low, Medium, High, Critical).

- **Live Status Indicator** – A green "All Clear" message means everything is fine. Red means act now.

## 🧠 Behind the Scenes – How It Works

You don't need to understand this part, but here's a peek at the technology:

SentinelAI is built with Python and uses a **RandomForest machine learning model**. This model was trained on real-world attack data (the CICIDS2017 dataset) which includes 15 different attack types. It also uses multiple databases (SQLite, MongoDB, and Redis) to store and process data quickly. The result is a system smart enough to learn your network's "normal" patterns and spot even subtle anomalies.
